## 润色时的"为什么"记录要求

每改写一处，必须在润色日志中说明：
- **原文写法的问题**：为什么原文的写法更差？（与角色性格/题材逻辑/阅读场景的哪条原则相矛盾？）
- **改写后的优势**：为什么新写法更优？（如何更好地符合角色性格/题材逻辑/阅读场景？）
- **底层逻辑**：这种改写遵循了什么可迁移规则？

示例格式：
```
[改写记录]
- 位置：第3段
- 原文：「她缓缓说道："不行。"」
- 问题："缓缓"是抽象副词，没有画面感；且当前角色为直球性格，动作应直接有力，"缓缓"与性格矛盾。
- 改写：「她把杯子搁下——"不行。"」
- 优势：前置动作具体有画面感，符合角色即时反应的性格；破折号制造停顿感，比副词更有节奏。
- 底层逻辑：副词选择=角色性格的外延。直球型角色用直接动作，内敛型角色用缓慢动作。
```
