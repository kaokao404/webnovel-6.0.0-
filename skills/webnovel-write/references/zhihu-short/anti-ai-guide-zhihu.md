# Anti-AI 写作指南

> 核心理念：写的时候就写对，比写完再改好。
> 加载时机：Step 2 起草正文前。

## 写作选择逻辑（理解"为什么"，而非背诵"不要"）

作为 LLM，你有以下根深蒂固的倾向。但对抗它们的最佳方式不是背诵禁令，而是理解"为什么这种写法会错"。

### 1. 闭环陷阱：每段写完整闭环

**为什么错**：闭环会杀死翻页动力。读者在段落末尾得到"总结"后，大脑会误判"这段结束了，可以停下来"，从而降低继续阅读的欲望。
**底层逻辑**：余味来自"未完成感"。人在面对未完成的信息时，会产生认知闭合需求（Zeigarnik effect），这会驱动他们继续读下去。
**正确做法**：删掉感悟/总结句，让段落停在动作、对话或一个新的疑问上。

### 2. 副词陷阱：用副词修饰一切

**为什么错**："缓缓""淡淡""微微"是抽象的——读者无法从"缓缓"中想象出具体的画面。更关键的是，副词选择=角色性格的外延。直球型角色动作应该直接、具体、有力量，"缓缓"暗示从容、心机、优雅，与直球性格矛盾。
**底层逻辑**：具体动作>抽象副词。"她把杯子搁下——'不行。'"比"她淡淡说道：'不行。'"更有画面感，也更符合角色的即时反应。
**正确做法**：删掉副词，用前置动作或结果暗示速度/力度。思考：这个角色在当前情绪下，动作应该是快还是慢？是直接还是犹豫？用身体部位的具体运动来表达。

### 3. 模板反应：所有角色同一套反应

**为什么错**："瞳孔微缩""心中一凛"是AI的默认反应库，不绑定任何角色性格。真实的人有不同的应激模式：急性子的人摔东西，内敛的人咬嘴唇，骄傲的人冷笑。
**底层逻辑**：角色的应激反应 = 性格 + 成长背景 + 当前关系。给每个主要角色设计2-3个专属微动作，在紧张/情绪波动时反复出现，形成辨识度。
**正确做法**：为每个角色建立"微动作签名"（如女主→咬唇、跺脚、抛媚眼；男主→转玉扳指、垂眼不与人对视）。

### 4. 辩论赛对话：角色完整理性表达

**为什么错**：真实对话中，人很少把真实想法全盘托出。对话是权力博弈的工具，弱势方会迂回、装傻、转移话题；强势方会打断、反问、不回答。
**底层逻辑**：对话的冲突强度 = 角色之间的权力差 + 信息差。权力差越大，对话越短、越绕、越潜台词化。
**正确做法**：让角色说话带意图（试探/回避/施压/诱导/防御）。弱势方不直接表达诉求，用威胁/撒娇/装傻迂回推进。每句对话表面说一件事，底下藏另一层。

### 5. 情绪标签："他感到愤怒"

**为什么错**：第一人称的代入感来自"我"的感官体验，标签化破坏"我在场"的幻觉。"他感到愤怒"是第三人称全知视角的特权——全知视角的叙事者可以直接读取角色内心，但第一人称的"我"只能通过感官推断他人情绪。
**底层逻辑**：第一人称的"感受"必须经由感官通道传递：视觉（瞪大、泛红）、触觉（捏得发白、发抖）、听觉（嗓音哑了半拍）、味觉（舌尖尝到铁锈味）。
**正确做法**：把"他感到愤怒"改写为"指节捏得发白，舌尖尝到铁锈味。再等一秒他就动手。"（生理反应+微动作+即将采取的行动）

### 6. 匀速信息：每段信息量差不多

**为什么错**：均匀节奏是AI的默认模式，因为训练数据中的说明性文本倾向于均匀分布信息。但人类思维有峰谷——紧张时句子变短变碎，平静时可以有长段描写。
**底层逻辑**：节奏对比制造情绪起伏。如果每段都是3-5句、长度均匀，读者会进入"阅读自动驾驶"状态，情绪不会被调动。
**正确做法**：刻意制造疏密对比。紧张场景→短句+单句成段；平静场景→长句+细节描写；转折处→一个超短句爆点。

### 7. 安全着陆：章末解决所有冲突

**为什么错**：冲突完美解决会消除翻到下一章的动力。章末是读者决定是否继续的决策点——如果所有问题都解决了，读者会说"挺好的，明天再看"。
**底层逻辑**：悬念维持 = 未闭合问题 > 已给出答案。最理想的结尾是"让角色做一个读者无法预测结果的决定"或"让一个新的阻碍出现"。
**正确做法**：至少留一个未解决的问题、一个新的阻碍、或一个让读者"等等，那接下来会怎样？"的疑问。

### 8. 展示后解释：动作+解释

**为什么错**：解释句像在教读者，暗示作者不信任读者的理解力。读者被"告诉"而不是"引导发现"，参与感归零。
**底层逻辑**：展示（show）的本质是让读者自己得出结论。如果展示后立刻解释，等于在考试中先给答案再给题目——读者失去了推理的快感。
**正确做法**：写完动作后信任读者。如果担心读者看不懂，说明展示不够具体——增强动作/对话本身的暗示力，而不是补解释句。

## 写作时的 5 个即时检查（带"为什么"）

每写完一个段落，快速过一遍——但不仅要检查"有没有犯"，还要追问"为什么这样更好"：

1. **闭环检查**：这段是否走完了"起因→经过→结果→感悟"？→ **为什么删掉感悟更好**：因为余味来自未完成感，闭环会杀死翻页动力。让读者自己体会，不要在段落末尾替他们下结论。
2. **副词检查**：最近 3 个动作描写是否用了"缓缓/淡淡/微微/轻轻"？→ **为什么删掉副词更好**：因为当前角色的性格决定了动作应该直接、具体、有力量（如果是直球型角色）。副词是抽象的，具体动作才有画面感。思考：这个角色在当前情绪下，动作是快还是慢？用身体部位的运动来表达，不要用副词概括。
3. **情绪检查**：角色的情绪是"告诉读者"还是"展示给读者"？→ **为什么展示更好**：第一人称代入感来自感官体验。"他感到愤怒"是第三人称全知视角的特权，第一人称的"我"只能通过视觉/触觉/听觉/味觉来推断他人情绪。把标签改写为"指节捏得发白，茶水洒了半桌"。
4. **对话检查**：这句对话是在推进冲突还是在解释背景？→ **为什么冲突更好**：对话是权力博弈的工具，不是信息传递的管道。弱势方不会直接表达诉求，强势方不会完整回应。每句对话表面说一件事，底下藏另一层意图。
5. **节奏检查**：最近 500 字的节奏是否均匀？→ **为什么不均匀更好**：人类思维有峰谷，均匀节奏会让读者进入"自动驾驶"状态。紧张时句子变短变碎，平静时可以有长段。刻意制造对比，插入一个短句爆点或一段沉默。

## 替代方案速查表（附"为什么"）

| AI 癖好 | 替代方向 | 示例 | 为什么这样更好 |
|---------|---------|------|----------------|
| "他感到愤怒" | 生理+微动作+决策 | "指节捏得发白，舌尖尝到铁锈味。再等一秒他就动手。" | 第一人称代入感来自感官体验，标签化破坏"我在场"的幻觉 |
| "缓缓说道" | 删副词，加前置动作 | "他把杯子搁下——'你确定？'" | 副词是抽象的，具体动作才有画面感；副词选择=角色性格的外延 |
| "眸中闪过一丝X" | 个性化行为 | "她咬了下嘴唇内侧"（紧张） / "他开始拧笔帽"（焦虑） | AI用同一套神态模板给所有角色，真实的人有专属应激模式 |
| "心中暗道" | 直接写内心句 | 删掉"心中暗道"四个字，后面的内容直接保留 | "心中暗道"是多余的叙述层，直接写内心句更沉浸 |
| 四段闭环 | 截断在高点 | 删掉最后的感悟句，让读者自己体会 | 余味来自未完成感，闭环会杀死翻页动力（Zeigarnik effect） |
| 全员书面语 | 口语化+个人口癖 | 加口头禅（"得了吧"）、省略（"走？""嗯。"）、打断 | 真实对话不连贯，有抢话、沉默、答非所问；对话承载权力博弈 |
| 段末总结 | 删总结句 | 用动作或对话结尾，不写"他终于明白了" | 总结句替读者下结论，剥夺了读者自己发现的快感 |
| 展示后解释 | 删解释句 | 写完"她把门摔上"后不要再写"她显然很生气" | 解释句像在教读者，暗示不信任读者理解力；展示足够强就不需要解释 |
| "更重要的是……" | 直接说事 | 删掉递进模板词，直接给信息 | 递进模板是AI的"安全词"，删掉后信息更直接有力 |
| 情绪即时切换 | 加过渡 | "他压下怒意，但声音还是哑了半拍" | 真实情绪有残留和回味，即时切换像开关，不真实 |

## 对话专项

好的对话特征：
- 有人抢话、有人沉默、有人答非所问
- 角色不会把真实想法全盘托出
- 不同角色有不同的说话节奏（有人啰嗦、有人惜字如金）
- said tag 不超过 30%，优先用前置动作（"他把烟掐灭——'行。'"）

坏的对话特征（你最容易写的）：
- A说→B说→A说→B说，严格交替
- 每句都完整回应上一句
- "XX说道""XX淡淡道"贯穿全篇
- 角色说话像在做报告

## 节奏专项

好的节奏特征：
- 有的段落只有一句话，有的段落有十几句
- 紧张时句子变短、变碎
- 平静时可以有长段描写
- 信息密集的段落和留白的段落交替出现

坏的节奏特征（你最容易写的）：
- 每段 3-5 句，长度均匀
- 信息密度恒定，无峰谷
- 转场全靠"时间飞逝""不知不觉"
